## IP-список Albion по отдельному запросу — 11 ноября 2026 года

Создан `subnets/albion.txt`: 17 точных IPv4 `/32` из трёх пользовательских захватов. SHA-256 входных CSV сверены с сохранёнными при предыдущем анализе. В источнике для каждого IP сохранено DNS-наблюдение и число открытых исходящих/ответных пакетов. Часть игровых адресов видна только в DNS успешных сеансов через Happ; они не объявлены выделенными или стабильными сетями игры. Источник `user-supplied`, автоматического обновления и независимой официальной проверки нет.

Включённые сервисные IP-списки могут покрывать одни и те же адреса: четыре новых `/32` уже входят в сети KinoPub. Общая сборка теперь убирает полностью покрытые CIDR между сервисами без укрупнения и слияния соседних сетей. Отдельный файл Albion сохраняет все 17 записей; отключение KinoPub возвращает точные маршруты в общую сборку. Равенство покрытия и поведение при отключении проверены тестами. Итог: 56 доменов и 59 CIDR в общих файлах.

Выполнено: **45 unittest-тестов успешно**, компиляция Python, сборка, валидация, `build_lists.py --check`, `git diff --check`. Публикация, серверные GitHub Actions и исправление входа через роутер после добавления IP не проверялись.
